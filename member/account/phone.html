M16 · Change phone (note 06). The kit's phone change: a code goes to the new number, which must not belong to another login (one phone per login). The kit ends other sessions. Afterwards GroFunder copies the number to every linked record (05 lets members update their own phone) and sends an SMS to the old number, so a stolen phone can't quietly move the login.

Try it: another member's number is refused; any other mobile number goes on to the code. The SMS sign-in code follows the new number with no extra step, because the factor reads the current phone (06).
