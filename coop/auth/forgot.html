S3 · The kit's reset screen (ForgotPasswordScreen). The code goes to the email, or by SMS to the phone on the login. The kit's reset ends every session, so a stolen session stops working too (note 09). The steps are states: loaded (where to send the code), code (the code and a new password), code-2fa (the same for someone with two-step verification), loading and error.

"If an account exists" is the kit's wording on purpose: the screen never says whether an address has a login.
