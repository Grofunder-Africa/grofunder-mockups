PinPad

A 4-digit PIN on large keys, the way members already enter an M-Pesa PIN. The phone's own keyboard is never shown, and digits are never shown, only dots.

Used in
Member sign-in, sign-up (set PIN), change PIN, forgot PIN, linking another membership (06)
Rules
Keys 64dp tall; dots announce "2 of 4 digits entered"; on the 4th digit it submits by itself; a wrong PIN shows the error and clears; the PIN rule (no 0000, 1234, 1212) is checked by the server, with its message under the dots
Two digits in
Wrong PIN

That ID number and PIN don't match.

Refused by the PIN rule (setting a PIN)

Choose a PIN that isn't a run like 1234 or a repeat like 1212.

Locked out

Too many tries. Try again in 15 minutes, or reset your PIN.

<PinPad length={4} value={pin} onChange={setPin} onComplete={submit}
        errorText={error} disabled={locked} helpLabel="Forgot your PIN?" onHelp={...} />
F4 · new

OtpInput

An SMS code, one box per digit (the backend kit's codes are 6 digits). Typing moves to the next box, a pasted or auto-filled code fills them all, and to a screen reader it is one field.

Used in
Every member sign-in (the SMS second factor), sign-up (claim), forgot PIN, change phone (06)
Rules
autocomplete="one-time-code" and Android's SMS retriever so the code fills itself; resend after 60 s, at most 5 an hour (06); the code works for 5 minutes
Typing

You can ask for another code in 0:42.

Wrong code

That code isn't right. 3 tries left.

Resend available 
<OtpInput length={6} value={code} onChange={setCode} onComplete={verify}
          errorText={error} resendIn={42} onResend={resend} />

"3 tries left" assumes the server says how many are left; the kit's OTP service allows 5 tries (06). If it doesn't return the count, the line is just "That code isn't right."

QuantityEntry

A decimal quantity typed in the unit the clerk measures in, with the stored figure worked out live underneath. Generic: a value, a unit, an optional factor to a base unit.

Used in
Record delivery, delivery import preview, edit delivery, rejected quantity (07); prices per recording unit (07)
Rules
Decimal keyboard; up to 3 decimals; above 0; the converted line uses the factor at the time of entry and is what gets stored (details.entered keeps what was typed)

litres

bags

MoneyField

Shillings typed, cents stored. "Ksh" fixed in front; grouping added as you type; never a float in between.

Used in
Prices (07), payout amounts per delivery and "pay an amount, oldest first", additions and deductions (08)
Rules
Value in cents (integer); two decimals at most; an optional maximum with its own message
Filled
Ksh
From 15 Oct 2026. Ksh 52.50 until then.
Over the maximum
Ksh
At most Ksh 8,748.00, the balance on this delivery.
<MoneyField label="Pay now" valueCents={cents} onChangeCents={setCents}
            currency="KES" maxCents={874800} maxText="the balance on this delivery" />

Avatar

A person's photo, or their initials, in a small square (4px corner, UI-8); an icon for a thing. The kit's LogoSticker is an organisation's mark with its own treatment; people need a light, small one for lists.

Used in
Member lists and detail (05), staff and team, nominees, the account button
Rules
Initials from the preferred name, else the full name; a photo from media_library when there is one; 32 / 40 / 64dp; decorative when a name sits beside it
