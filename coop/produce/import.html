C7 · From note 07 (UI-30). A spreadsheet of deliveries, imported all or nothing. Every row gets the same rules and unit conversion as recording one by hand. If any row breaks a hard rule, nothing is imported, and the check lists every row's problem so the file can be fixed in one go. Soft checks (a day the round doesn't run, a second delivery in a round) are listed but don't stop the import. Imported rows get the source "Imported".

The file in this mockup is Kijani's deliveries of 29 October from the shared data, with five rows broken on purpose. Use the states to see the check with problems, a clean check, and the import done.

G30 · The file's columns aren't defined in note 07 or the build plan. This page proposes: member number, date, product, grade, quantity (in the recording unit where there is one), round, centre and receipt, with a template to download. It needs the backend's agreement.
