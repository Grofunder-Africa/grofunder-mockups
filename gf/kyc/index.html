K1 · Verifications (note 20, draft revision 2). One row per visit: an agent's check of one member, and a reviewer's decision. It opens on To review, the visits agents have submitted, oldest first, because that's the office's daily work. Filters: cooperative and agent; search by member name or number.

Who does what (note 20): View only reads (kyc.view). Operations and up open verifications and assign agents (kyc.assign), and approve, send back or fail (kyc.review), never on a visit they did themselves. Farmer Support Agents don't see this page: their navigation is My visits.

Warnings are the soft checks worked out when the agent submits (note 20): a reused photo, a farm point near another member's verified farm, photos far from the farm, a declared size far from what the agent saw, the ID differing from the cooperative's record.
