C24 · From note 01. Clusters group the cooperative's members: a collection centre, a zone or a village group, one level deep. Needs cooperatives.manage_clusters, which only a cooperative's own staff can hold: administrators and managers.

Page, panel or dialog (UI-13). Add is a dialog (three fields). A cluster opens as a panel: name, place, description and address, with Archive or Reactivate, and Delete for a cluster that never had members.

Rules (01). A name is used once in the cooperative, archived or not. Typing an archived cluster's name offers to reactivate it instead of refusing (try "Tinganga" at Kijani). Archived clusters leave the pickers and stay in members' history. Delete only works while nothing points at it.
