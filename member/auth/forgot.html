M4 · Forgot PIN (note 06). The kit's reset by an SMS code to the login's phone; holding the phone is the proof, so the ID isn't asked again. The new PIN follows the PIN rule. Every session ends, so other phones are signed out.

The same answer either way: the code step says "if this matches a login", so the screen doesn't confirm who has one (06).

Gap: a lost number. The reset code goes to the login's phone, sign-up refuses an ID that already has a login, and nothing in note 06 lets staff or GroFunder move a login to a new number. So a member who loses their number has no way back in. Logged for the backend.
