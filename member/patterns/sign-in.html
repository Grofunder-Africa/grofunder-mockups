Pattern sample: member sign-in (phase 2). From note 06: the ID number (or the phone) and a 4-digit PIN, then an SMS code every time. The steps are the page's states. The member app flow (phase 9) designs sign-up (claim), forgot PIN and linking from the same note.

ID type. The ID type is chosen first because the sign-in name is built from it (P + number for a passport, A + number for an alien ID), so a national ID number can never collide with another type. ChoiceChips and a TextField: no new component.

F1 and F4. The kit has no phone/ID + PIN + SMS-code sign-in screens (F1), and no PinPad or OtpInput (F4). Both are proposed in specimens/new-components.html.
