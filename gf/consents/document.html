CN2 · Consent document (note 22; the kit's admin/documents/{id}/). One document: whose it is, what kind, which slots it is bound to, and every version in each language, marked in force, scheduled, past, archived or draft. A version opens its wording (CN3). Published wording never changes; a change is a new version.

Writing a new version (Full and Owner) starts a draft in both languages, each copied from the one in force (the kit's start_draft). One draft per language at a time. Binding (Full and Owner) points a slot at this document: for a lender's sharing document, loan.sharing for that lender; for a lender's own agreement, loan.agreement for that lender, which then wins over GroFunder's.
